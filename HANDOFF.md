## The live decision: which blank

**The blocking question is answered.** Full detail and method in `pod-suppliers.md`; the short version:

> **Does a given AS Colour colourway exist in both a tee and a sweatpant?**
> **Yes — six of them**, at identical hex: Bone `#D1CDCA`, Butter `#F4F0D7`, Cypress `#51594A`, Shadow `#626367`, Athletic Heather `#A4A4A2`, Black `#000000`.

So the one-house thesis **holds**. Stay on Apliiq, change the blank from Comfort Colors to AS Colour: Apliiq carries **243** AS Colour products against **13** Comfort Colors, spanning tees, crews, hoods, pants, shorts and jackets.

**The catch:** across the *full* core four, exact hex matching gives only **three** — Bone, Athletic Heather, Black. Not because the shorts palette is small (15 colours across 9 men's styles) but because **no single shorts style carries more than three colours**, and the three-colour styles don't agree with each other. Accepting a different shorts *cut* per colour gets you to 5, which isn't really a system.

**Resolved by the tonal-break rule.** Shorts run one shade *lighter* in the same hue rather than hex-matching. The fit still reads as one colour, and you gain a deliberate break at the waist. AS Colour already makes this — the **Faded** line (Faded Track Shorts 5939, Faded Track Pants 5938) is washed-down siblings of the base colours.

Staying inside one silhouette family (Relax Track Shorts 5933 + 5939), the matrix reaches **9 anchors, 8 with a matching pant**. The cleanest, all with pant available:

| Top | Short | ΔL |
|---|---|---|
| Athletic Heather `#A4A4A2` | Bone `#D1CDCA` | 0.13 |
| Athletic Heather `#A4A4A2` | Faded Bone `#EAE7E2` | 0.21 |
| Shadow `#626367` | Athletic Heather `#A4A4A2` | 0.22 |
| Bone / Athletic Heather / Black | same colour, exact | — |

Matched in OKLCh so "one step lighter" behaves consistently across hues. **Target ΔL 0.13–0.22** — the 0.06–0.08 pairings (Shadow/Faded Grey, Bone/Faded Bone) are subtle enough to risk reading as a laundry accident, and dye-lot variation could swamp them. Check those against physical swatches.

Caveats: measured from AS Colour's **US DTC site**, not Apliiq's per-product colour lists — those render client-side and need `get_product` (i.e. credentials). Two things to confirm once creds land: that Apliiq's colour lists match, and that Apliiq **carries the Faded line at all** — the 9-colour answer leans on it.

## Ground rules worth not relearning

- `APLIIQ_SHARED_SECRET` never enters git. `.env` is gitignored and CI fails if one becomes tracked. If it ever *is* committed, rotating it in the Apliiq dashboard is the fix — removing the commit is not enough.
- Secret scanning / push protection are **unavailable** on this repo: it is private, and those are free only on public repos (otherwise they need paid GitHub Advanced Security). The CI guard is the compensating control.
- Under stdio, **stdout belongs to the MCP protocol**. A single `console.log` anywhere in the server process corrupts the stream. Diagnostics go to stderr.
- Don't build against unconfirmed API shapes. Spec §5 sets this rule for the order endpoints; it applies generally.
